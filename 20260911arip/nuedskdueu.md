# 广州妇女儿童医疗中心试管婴儿不算贵，不同技术花费不同

> 更新时间：2026-09-11 (UTC+8)

符合供试管条件的不孕不育患者可以在广州市妇女儿童医疗中心进行供助孕，而目前该医院可以做一、二以及单身三代试管，不同技术费用是有差异的，做一次一代供试管费用在4万元左右，做一次二代供试管的费用在4.5万元左右，而三代供试管费用要贵一些，大概要7-10万左右，当然每个患者身体情况不同，最终的费用要因人而异。

广州市妇女儿童医疗中心（广州妇幼保健院）是一家三甲专科医院，1997年成立生殖医学中心，开展辅助生殖技术，目前已经开展了**宫腔内人工授精、一代、二代、单身三代试管技术，而该医院也可以进行供助孕，这里就为大家分享下在该医院做一次供试管的费用情况：

- 1. 前期检查费：夫妻双方都要做一系列检查，以确定是否符合做供试管的条件，一般检查费在5000-8000元左右；
- 2. 促排治疗费：费用在8000-15000元左右，具体看患者用药种类和剂量，用进口药费用就比较贵；
- 3. 供的费用：在广州市妇女儿童医疗中心做供试管，精源是需要医院向精子库申请，涉及到的费用就主要是精子购入、运输以及储存管理等，一般在5000元左右；
- 4. 实验室操作及手术费：包括促排手术、精液解冻以及优化处理、体外受精或单精子显微注射受精、胚胎培养、胚胎筛查、胚胎冷冻以及移植等等费用，其中单精子显微注射受精是二代试管的费用，胚胎筛查是单身三代试管的费用，所以这部分费用具体多少看患者采用的试管技术，通常是在15000元左右，二代会多3000元，三代可能会多个20000-30000元左右；
- 5. 其他费用：就是试管治疗过程中一些疾病的治疗费用以及移植后的保胎用药费用，大概需要50000-10000元左右。

所以说，在广州市妇女儿童医疗中心做一次供试管婴儿的费用是需要根据每个患者的实际情况来定的，而且如果一次不成功，总费用就会更多。
